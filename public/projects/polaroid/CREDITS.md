# Polaroid portfolio cover

Original SVG composition made for this portfolio, using typography and instant-print frames. No image-generation tool was used.

The lake and sea photographs are the existing sample assets from [overlytiwa/Polaroid](https://github.com/overlytiwa/Polaroid/tree/main/public/samples), reused under the [Unsplash license](https://unsplash.com/license). The source project identifies them as Unsplash images `1476514525535-07fb3b4ae5f1` and `1518837695005-2083093ee35b`.

The cover embeds reduced-size JPEG copies so it remains self-contained when displayed as an image.
