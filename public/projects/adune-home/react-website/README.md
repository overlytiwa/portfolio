# ADUNÉ — Modern Vite / React 18 project

```bash
npm install
npm run dev
```

This is the editable, conventional React development project. Runs the same homepage, shop, story, journal and interaction components as the portable static preview one directory above. React components are authored in JavaScript using `React.createElement` for no-JSX parity with the offline edition; the source is in `src/main.jsx` and can be split into JSX modules later. Assets are in `public/assets`.

**Not production commerce:** No live payment, mailing list, inventory, analytics, verified product photography or merchant API. Consult the package research and documentation before use.
